# Writing Docs

sdocs recognizes three types of doc files, each for a different purpose.

- [Component docs (`.sdoc`)](./component-sdoc.md) — document a single component with interactive controls
- [Page docs (`.page.sdoc`)](./page-sdoc.md) — freeform prose with auto-generated TOC
- [Layout docs (`.layout.sdoc`)](./layout-sdoc.md) — component compositions in an isolated iframe
