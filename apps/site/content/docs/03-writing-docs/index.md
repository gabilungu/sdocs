---
title: Writing Docs
---

sdocs recognizes three types of doc files, each for a different purpose.

- [Component docs (`.sdoc`)](/docs/writing-docs/component-sdoc) — document a single component with interactive controls
- [Page docs (`.page.sdoc`)](/docs/writing-docs/page-sdoc) — freeform prose with auto-generated TOC
- [Layout docs (`.layout.sdoc`)](/docs/writing-docs/layout-sdoc) — component compositions in an isolated iframe
