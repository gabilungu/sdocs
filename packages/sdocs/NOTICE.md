## Font Awesome Free

The two **semantic** icon sets — the `[COMPONENT]` `status` glyphs and the
`[NOTES]` type glyphs — are from
[Font Awesome Free](https://fontawesome.com) 7.3.1, used under
**CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/).

Copyright 2026 Fonticons, Inc.

They live in `src/lib/ui/Icon/icons/fa/` (`dist/ui/Icon/icons/fa/` when
published) and each file keeps the Font Awesome attribution comment it was
distributed with; that comment travels into the built bundle with the icon.

Only **free-tier** icons are included. Font Awesome Pro is commercial software
whose licence does not permit redistribution, so no Pro icon is in this
package, and none may be added to it.
